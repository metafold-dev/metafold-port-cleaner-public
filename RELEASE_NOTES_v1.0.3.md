# MetaFold Port Cleaner v1.0.3

Bu sürüm Samsung USB Driver paketindeki uyumsuz INF dosyalarının kurulum sonucunda yanlış şekilde başarısız görünmesini düzeltir.

## Değişiklikler

- Eski Win9x tabanlı Samsung INF dosyaları otomatik atlanır.
- 64-bit Windows üzerinde 32-bit-only Samsung INF dosyaları otomatik atlanır.
- Sürücü yönetimi ekranında Samsung kurulum sonucu daha temiz ve anlaşılır görünür.

## Not

Samsung paketinin içinde farklı Windows dönemleri ve mimarileri için çok sayıda INF bulunur. Program artık yalnızca mevcut Windows mimarisine uygun INF dosyalarını Driver Store akışına gönderir.
