# MetaFold Port Cleaner v1.0.1

OTA update support build.

## Added

- Automatic update checks through the public `update.json` manifest
- Manual update check from the Help menu
- Startup update check preference in Options
- SHA256 verification before starting downloaded setup files

## Install / Run

1. Download `MetaFoldPortCleanerSetup-v1.0.1-win-x64.exe`.
2. Run the installer.
3. Follow the setup wizard.
4. Start MetaFold Port Cleaner from the Start menu or desktop shortcut.

## Notes

- Source code is not included in this public release.
- Future builds can be delivered through the OTA manifest after the app is installed.
- Driver operations may require administrator permission and Windows restart depending on the selected action.
