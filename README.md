# MetaFold Port Cleaner

<p>
  <img src="assets/metafold-port-cleaner-logo.png" alt="MetaFold Port Cleaner" width="180">
</p>

MetaFold Port Cleaner is a Windows service utility for repair desks and technical service workflows. It helps clean non-present device records, track occupied COM ports, and manage commonly used mobile service drivers from a single interface.

> Source code is private. This public repository is for product information, screenshots, release notes, and downloadable builds only.

## Features

- Lists non-present Windows device records
- Shows occupied COM ports for disconnected devices
- Removes selected stale device records
- Includes ready-made sorting presets for date, port, COM/ADB/USB priority, manufacturer, class, and Device ID
- Includes Turkish and English language support
- Includes light and dark theme support
- Provides a driver manager for MediaTek, Qualcomm, Rockchip, Spreadtrum, USBdk, Universal ADB, Huawei USB, and Samsung USB drivers
- Supports safe scheduled cleanup prompts with current scan counts before removal
- Supports OTA update checks through GitHub Releases
- Includes Windows Device Manager shortcut
- Includes Task Manager Pro shortcut powered by bundled Microsoft Sysinternals Process Explorer

## Requirements

- Windows 10 or newer
- Administrator permission for device cleanup, driver install/remove, and driver signature settings

## Notes

Some actions modify Windows device records or driver store entries. Use administrator mode and review selected devices before removal.
