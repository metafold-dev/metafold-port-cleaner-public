# MetaFold Port Cleaner v1.0.4

Bu sürüm Huawei USB Driver desteğini ekler.

## Değişiklikler

- Huawei x64 ve x86 sürücü dosyaları paketlendi.
- Sürücü yönetimi ekranına Huawei USB Driver satırı eklendi.
- x86/x64 klasör ayrımı olan sürücülerde yalnızca mevcut Windows mimarisine uygun INF dosyaları işleme alınır.

## Not

64-bit Windows üzerinde Huawei paketinden x64 INF dosyaları yüklenir; x86 klasöründeki INF dosyaları otomatik atlanır.
