# MetaFold Port Cleaner v1.0.8

Bu sürüm servis ekranına Görev Yöneticisi Pro kısayolu ekler.

## Değişiklikler

- Üst komut çubuğuna Görev Yöneticisi Pro butonu eklendi.
- Buton, paket içindeki Microsoft Sysinternals Process Explorer aracını yönetici olarak açar.
- Windows mimarisine göre procexp64.exe, procexp64a.exe veya procexp.exe otomatik seçilir.
- Process Explorer Eula.txt dosyası paket içinde tools\ProcessExplorer altında yer alır.

## Kurulum

1. MetaFoldPortCleanerSetup-v1.0.8-win-x64.exe dosyasını indirin.
2. Kurulumu çalıştırın.
3. MetaFold Port Cleaner'ı Başlat menüsünden açın.
4. Cihaz temizleme, sürücü işlemleri ve Görev Yöneticisi Pro için yönetici izni gerekebilir.
