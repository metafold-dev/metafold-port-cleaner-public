# MetaFold Port Cleaner v1.0.0

First public Windows build.

## Included

- MetaFold Port Cleaner executable
- Bundled driver packages
- MetaFold branding assets required by the app

## Install / Run

1. Download `MetaFoldPortCleaner-v1.0.0-win-x64.zip`.
2. Extract the zip file.
3. Run `MetaFoldPortCleaner.exe`.
4. Use administrator mode for cleanup and driver actions.

## Notes

- Source code is not included in this public release.
- Driver operations may require administrator permission and Windows restart depending on the selected action.
