# MetaFold Port Cleaner v1.0.2

Samsung driver package build.

## Added

- Samsung USB Driver support in Driver Manager
- Samsung installer EXE was extracted into direct INF/CAT/SYS driver files
- Samsung driver installation now uses the same Driver Store flow as the other bundled INF packages

## Install / Run

1. Download `MetaFoldPortCleanerSetup-v1.0.2-win-x64.exe`.
2. Run the installer.
3. Follow the setup wizard.
4. Start MetaFold Port Cleaner from the Start menu or desktop shortcut.

## Notes

- Source code is not included in this public release.
- Driver operations may require administrator permission and Windows restart depending on the selected action.
